# AZ-104 Endpoint Architect's Blueprint for Azure & M365 Automation

> A GitHub repository for Azure administration and M365 automation, focusing on endpoint architect needs, featuring a PowerShell script for secure Azure infrastructure deployment and a PHP-based M365 SaaS engine frontend.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/az104-endpoint-architect-automation.git
cd az104-endpoint-architect-automation

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```

## Tech Stack

PowerShell, Azure CLI, Microsoft Graph, PHP

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph CLI (if applicable)
- Appropriate administrative permissions
